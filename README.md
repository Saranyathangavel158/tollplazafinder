# Toll Plaza Finder

A full-stack application that finds toll plazas along a driving route between two Indian PIN codes.

## Project structure

```
toll-plaza-finder/
├── backend/     Spring Boot REST API (Java 21, Maven)
├── frontend/    React application (to be added in the next phase)
└── README.md    This file
```

## Backend

The backend lives in [backend/](backend/). Its full documentation, including setup,
API reference and Geoapify API key configuration, is in [backend/README.md](backend/README.md).

Run the tests from the backend directory:

```
cd backend
mvn clean test
```

The [frontend/](frontend/) folder is a placeholder. The React application will be created here.
